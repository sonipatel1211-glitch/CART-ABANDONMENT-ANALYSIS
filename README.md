# CART-ABANDONMENT-ANALYSIS


##  Project Overview
Cart Abandonment Analysis is a data analytics project focused on understanding customer drop-offs during the e-commerce checkout process. The project uses SQL and Power BI to analyze customer behavior, identify critical checkout stages, and help businesses improve purchase conversion rates.

##  Business Objectives
- Identify the checkout stage with the highest customer drop-off.
- Analyze cart abandonment across different device types.
- Understand abandonment patterns by product category.
- Analyze cart abandonment by time of day.
- Provide data-driven insights to help improve the checkout experience and increase conversions.

##  Tools & Technologies
- SQL: Data analysis and querying.
- Power BI: Interactive dashboard development and data visualization.
- DAX: Measures and calculations for key performance indicators.
- Power Query: Data cleaning and transformation.

##  Key Performance Indicators (KPIs)
- Total Sessions
- Purchase Sessions
- Purchase Conversion Rate
- Cart Abandonment Rate
- Checkout Funnel Drop-off

##  Dashboard Features
- KPI Cards: Overview of sessions, purchases, conversion, and abandonment.
- Checkout Funnel: Tracks customer progression through checkout stages.
- Device Analysis: Compares customer drop-off across device types.
- Product Category Analysis: Identifies categories with higher abandonment.
- Time-of-Day Analysis: Examines abandonment patterns throughout the day.

##  Business Questions Answered
1. At which checkout stage do the most customers drop off?
2. Which device types have higher cart abandonment?
3. Which product categories experience more abandonment?
4. At what time of day is abandonment highest?
5. Which areas should the product team prioritize to improve conversions?

##  Expected Business Value
The analysis helps identify potential friction points in the checkout journey. These insights can support better checkout design, improved mobile experiences, and more informed product decisions.
